# Skills dérivés du projet TransmiLab 3D

| Skill | Rôle |
|---|---|
| simulateur-3d-pedagogique | Construire un simulateur 3D (Three.js) exact, procédural, avec coupe/éclaté/pannes et livraison monofichier/Vercel |
| diagnostic-pedagogique-ux | UX « décortiquer » + « chercher la panne » en 6 étapes, clair/sombre, zéro chevauchement |
| pptx-cinematique-depuis-app | PPTX futuriste (transitions p14, animations d'entrée, vidéos réelles) à partir d'une app |
| capture-webgl-headless | Tester/capturer/filmer une app WebGL avec Playwright (rendu logiciel) |

Installation : déposer chaque dossier (ou le .skill correspondant) dans ~/.claude/skills/ ou l'importer dans Claude.
Ordre conseillé pour un nouveau projet : simulateur-3d-pedagogique → diagnostic-pedagogique-ux → capture-webgl-headless → pptx-cinematique-depuis-app.
